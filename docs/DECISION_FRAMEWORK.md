# 材料中心的设计与应用决策框架

## 目标

将“材料学表征 + 制备工艺 + 生物学验证”统一成一个决策闭环：在满足安全性、稳定性和设备边界的前提下，寻找能够提升目标杀伤性能的材料和工艺组合。

## 1. 参数如何分组

### 材料组成参数

- Mg/Si 比和各原料质量；
- 原料类型：自合成原料或商品原料；
- 必要时加入纯度、批次和供应商作为可追溯字段，而不是直接当作可优化连续变量。

### 制备工艺参数

`synthetic` 分支优先优化 Mg/Si 比、SHS 合成温度、保温时间、真空循环和初始压力；`commercial` 分支不优化 SHS 参数，而优化球磨时间、球料比、目标粒径、后处理和分散条件。两条分支都必须经过球磨和粒径控制。

### 应用条件参数

浓度、暴露时间、细胞系和后处理方式应作为实验条件进入模型。细胞系在同一轮训练中应固定，跨细胞系比较时要分层建模，不能把不同细胞系当成同一种响应。

## 2. 需要实现的指标

推荐至少定义以下三个层次：

1. **效果目标**：目标细胞杀伤率、抑制率或其他已验证的生物活性指标，通常是最大化。
2. **安全目标/约束**：非目标细胞存活率、溶血/炎症等安全指标，必须设定最低可接受门槛；若数值方向相反，则在建模配置中统一为“越大越好”或明确最小化。
3. **稳定性约束**：粒径、分散稳定性、储存稳定性和批间重复性，作为硬约束或第三目标，避免只优化一次性高活性样品。

最终的实验候选不是单一最高分，而是安全可行域内的 Pareto 候选。若项目组有明确的安全底线，应先硬过滤，再用 EHVI 排序；不能用平均分掩盖安全性失败。

## 3. 建议的实验优化顺序

### 第一期：补齐可识别性

优先补齐每个样品的材料身份、原料分支、Mg/Si 比、SHS 温度/真空/保温参数、球磨参数、粒径和两个目标。缺失关键工艺时不用于推断参数方向。

### 第二期：分支内探索

分别在 `synthetic` 和 `commercial` 分支内建模，先用覆盖设计或空间填充设计确认响应面，再使用多目标 BO 选择下一轮实验。不要把两条工艺路径的不可比参数强行放在同一个连续空间中。

### 第三期：验证参数方向

对模型认为最重要的 1 到 3 个参数做局部受控实验，例如围绕推荐的 SHS 温度、Mg/Si 比、球磨时间或目标粒径进行邻域扫描。这样才能区分相关性与可操作的改进方向。

### 第四期：稳健性验证

对 Pareto 候选进行重复批次、稳定性和非目标细胞安全验证。只有在效果、安全和稳定性均满足要求后，才把该候选标记为应用候选。

## 4. 候选输出必须包含什么

每个候选至少要包含：

- 候选编号和来源材料编号；
- `workflow_branch`、`synthesis_required`；
- 原料组成、Mg/Si 比；
- 合成温度、保温时间、真空/压力条件（仅合成分支）；
- 球磨时间、球料比、目标粒径、后处理方式；
- 细胞系、浓度和暴露时间；
- 两个目标的预测值/不确定性、Pareto 或 EHVI 排名；
- 安全性和设备可执行性检查状态。

如果候选缺少上述任一关键制备字段，它只能作为“待补数据记录”，不能作为实验处方。商品原料候选的 SHS 字段应为 `not_applicable`，不能用合成材料的统计值填充。

## 5. 模型解释与回写

模型推荐只能提出“下一步验证什么”，不能直接宣称“提高某参数必然提高杀伤”。每轮实验完成后，应把实际工艺、表征、细胞学结果和失败原因一并回写，并保存候选版本和模型版本。连续两轮方向不稳定时，应优先检查数据映射、目标单位、批次效应和分支混杂，而不是盲目增加 BO 轮数。
